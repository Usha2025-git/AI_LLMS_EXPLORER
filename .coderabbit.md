# CodeRabbit Configuration

This repository is configured to work with **CodeRabbit** for automated code reviews and suggestions.

## What CodeRabbit Does

CodeRabbit will automatically review your pull requests and provide:

1. **Code Quality Checks**
   - TypeScript/JavaScript type safety
   - Python best practices
   - Code style and formatting suggestions

2. **Security Reviews**
   - API key exposure detection
   - Security vulnerability scanning
   - Sensitive data identification

3. **Performance Suggestions**
   - Performance optimizations
   - Best practices for React/Next.js
   - Python performance improvements

4. **Accessibility Checks**
   - React component accessibility
   - ARIA label verification
   - Semantic HTML validation

## Configuration Files

- **`.coderabbit.yaml`** - Main configuration file for CodeRabbit
- **`.github/coderabbit.yml`** - GitHub-specific configuration
- **`website/.eslintrc.json`** - ESLint configuration for the website (used by CodeRabbit)

## What Gets Reviewed

### Website Code (`website/`)
- TypeScript/React components
- Next.js best practices
- Tailwind CSS usage
- Accessibility compliance
- Performance optimizations

### Python Applications
- Code quality and best practices
- Security (especially API key handling)
- Error handling
- Type hints and docstrings
- Async/await usage

### Configuration Files
- JSON, YAML, TOML syntax
- Security checks (no hardcoded secrets)

## Ignored Files

CodeRabbit will **NOT** review:
- `node_modules/` directories
- `.next/` build directory
- `__pycache__/` directories
- `.env` files (security)
- Lock files (`package-lock.json`, `yarn.lock`, etc.)

## How to Use

1. **Install CodeRabbit GitHub App** (if not already installed)
   - Go to your repository settings
   - Install CodeRabbit from GitHub Marketplace

2. **Create a Pull Request**
   - CodeRabbit will automatically review your PR
   - Check the comments on your PR for suggestions

3. **Review Suggestions**
   - CodeRabbit will provide detailed feedback
   - You can ask follow-up questions using `@coderabbit`

## Example Usage

When you create a PR, CodeRabbit will automatically:
- Review all changed files
- Provide suggestions and improvements
- Highlight potential issues
- Suggest best practices

## Configuration Updates

If you need to adjust CodeRabbit's behavior, edit:
- `.coderabbit.yaml` - Main configuration
- Or create a `.coderabbit.yaml` in a subdirectory for path-specific settings
